🔥 FIREBASE SETUP INSTRUCTIONS 🔥
=====================================

Firebase is now integrated! Follow these steps to set up YOUR OWN Firebase project:

STEP 1: Create Firebase Project
================================
1. Go to: https://console.firebase.google.com/
2. Click "Add project"
3. Project name: "mohamedrawan-engagement" (or any name you like)
4. Click Continue
5. Disable Google Analytics (not needed)
6. Click "Create project"
7. Wait 30 seconds, then click "Continue"

STEP 2: Enable Realtime Database
=================================
1. In your Firebase project, click "Realtime Database" in left menu
2. Click "Create Database"
3. Choose location: "United States (us-central1)" or closest to Egypt
4. Start in "Test mode" (we'll secure it later)
5. Click "Enable"

STEP 3: Get Your Configuration
===============================
1. Click the gear icon ⚙️ (Settings) → "Project settings"
2. Scroll down to "Your apps"
3. Click the "</>" icon (Web app)
4. Register app name: "Mohamed & Rawan Website"
5. DON'T check Firebase Hosting
6. Click "Register app"
7. You'll see firebaseConfig code - COPY IT!

STEP 4: Update index.html
==========================
1. Open index.html
2. Find this section (near the end):
   
   const firebaseConfig = {
       apiKey: "AIzaSyBFw0Qbyq9zTFTd-tUY6dZJQ3JZw6Vj5g8",
       authDomain: "mohamedrawan-engagement.firebaseapp.com",
       ...
   };

3. REPLACE with YOUR config from Step 3

STEP 5: Set Security Rules (Important!)
========================================
1. In Firebase Console, go to "Realtime Database"
2. Click "Rules" tab
3. Replace with these rules:

{
  "rules": {
    "messages": {
      ".read": true,
      ".write": true,
      "$messageId": {
        ".validate": "newData.hasChildren(['image', 'author', 'timestamp'])"
      }
    }
  }
}

4. Click "Publish"

STEP 6: Test It!
================
1. Open your website on your laptop
2. Open it on your phone
3. Draw/write a message on your phone
4. Check your laptop - message should appear instantly! 🎉

TROUBLESHOOTING:
================
If messages don't sync:
1. Press F12 → Console tab
2. Check for errors
3. Make sure you replaced the firebaseConfig
4. Make sure Realtime Database is enabled
5. Make sure Rules are published
